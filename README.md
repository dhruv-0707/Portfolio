# Dhruv Nautiyal - Portfolio Website

A modern, responsive personal portfolio website showcasing my skills, education, and projects as a software developer.

## 🌟 Overview

This is a personal portfolio website for Dhruv Nautiyal, a BTech student in Electronics and Communication Engineering at Malaviya National Institute of Technology, Jaipur. The website features a clean, professional design with smooth animations and an intuitive user interface.

## ✨ Features

- **Responsive Design**: Fully responsive layout that works seamlessly across desktop, tablet, and mobile devices
- **Smooth Navigation**: Single-page application with smooth scrolling to different sections
- **Interactive UI**: Dynamic typing animation in the intro section
- **Project Showcase**: Dedicated sections for displaying projects with images and descriptions
- **Contact Information**: Easy access to social media profiles and contact details
- **Modern Aesthetics**: Clean, professional design with a dark theme

## 🛠️ Technologies Used

- **HTML5**: Semantic markup for structure
- **CSS3**: Custom styling with modern CSS features
- **JavaScript**: Interactive functionality and smooth scrolling
- **Typed.js**: Typing animation library for dynamic text display
- **Google Fonts**: Poppins font family for typography

## 🚀 How to Use

1. **Clone the repository**:
   ```bash
   git clone https://github.com/dhruv-0707/Portfolio.git
   ```

2. **Navigate to the project directory**:
   ```bash
   cd Portfolio
   ```

3. **Open in browser**:
   - Simply open `index.html` in your web browser
   - Or use a local server for better experience:
     ```bash
     # Using Python
     python -m http.server 8000
     
     # Or using Node.js
     npx serve
     ```

4. **View the website**:
   - Open your browser and navigate to `http://localhost:8000`
